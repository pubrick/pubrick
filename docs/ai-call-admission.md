# Physical model call admission

Hosted dispatch uses `withHostedAiCall` once per physical request, including each retry. Forward its combined `signal` to the SDK or HTTP request. The wrapper starts its fixed budget before SQL: text and image 120 seconds, embedding and diagnostics 30 seconds. API and worker callers must use a database pool with a 5-second connection acquisition timeout. Transactions set statement and lock timeouts to 5 seconds.

Lock order is shared run-admission advisory, organization KEY SHARE, then central billing state. Normal calls resolve the published subscription and configured operator identity and count all unexpired leases in that organization. A diagnostic probe is a separate one-slot exception that works before subscription activation; it can add at most one call beyond the normal plan limit. Its daily API budget is a separate control. It grants no generation trial. Self-hosted installations create no lease or billing transaction; production integration attaches this scope only in hosted mode.

The committed UUID fence stores only tenant, kind and database-clock timestamps. Expiry adds 60 seconds to the fixed dispatch deadline. No transaction or connection stays open during SDK I/O. Final cleanup deletes only the exact tenant and UUID; failure retains the conservative lease until TTL and cannot turn a successful SDK request into a retry. Each admission removes at most 1,000 expired rows in its own tenant; operational cleanup of inactive tenants is separate.

Cancellation waits for the actual SDK promise to settle before releasing a lease. Callers must forward the signal on every path: a callback that ignores cancellation can remain pending, and crash recovery reclaims its lease by TTL. This bounds client HTTP dispatch under cooperative SDK cancellation; it cannot prove when a provider stops computing after disconnect. No automatic waiting queue, heartbeat, free trial, Redis, prompts, keys, or response data are introduced. This package alone does not establish application-wide coverage; all physical text, image, embedding and probe paths must be integrated and gated separately.
